# E-commerce Sales Analysis (Synthetic Data)

Beginner Python/pandas project using **5,000 simulated orders**. This is not real company data.

## Files
- `Ecommerce_Sales_Analysis.ipynb` — notebook with cleaning, questions and charts
- `ecommerce_sales_synthetic.csv` — input data
- `cleaned_ecommerce_sales.csv` — generated by running the notebook

## Questions
1. How did monthly completed sales change?
2. Which product categories generated the most sales?
3. Which regions generated the most sales?
4. How many customers made repeat purchases?
5. Which categories had the highest returned-order rates?

Also calculates average completed order value.

## Cleaning
Inspect missing values and duplicates, fill missing region/payment labels with `Unknown`, parse dates, remove invalid price/quantity and missing-date rows, and create sales and month columns.

## Run in Google Colab
1. Upload `Ecommerce_Sales_Analysis.ipynb` to Colab.
2. In a code cell, run `from google.colab import files; files.upload()` and choose `ecommerce_sales_synthetic.csv`.
3. Run notebook cells from top to bottom.

## Limitations
All results are simulated. Revenue is not profit. Return rate is based on orders marked Completed or Returned, not all placed orders. Every row represents one order in this generated dataset.
